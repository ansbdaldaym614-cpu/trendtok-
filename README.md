# TrendTok
نسخة MVP عربية ومهيأة للموبايل.

## الحالة الحالية
- Feed رأسي للفيديوهات
- تشغيل تلقائي للفيديو الظاهر
- إعجاب ومشاركة
- نشر فيديو من الجهاز وحفظه محلياً
- إعلان تجريبي بعد كل فيديوهين
- واجهة RTL عربية

## الخطوة التالية
ربط تسجيل الحسابات + قاعدة البيانات + تخزين الفيديوهات + لوحة الإدارة + نظام إعلانات الشركات + البلاغات والمراجعة، ثم تغليف المشروع كتطبيق Android.
